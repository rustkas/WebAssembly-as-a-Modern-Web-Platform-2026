# Приложение A. Справочник по инструкциям WASM

WebAssembly — это стековая виртуальная машина, где каждая инструкция либо помещает значение на стек, либо снимает значение (или значения) со стека и помещает результат обратно . В этом приложении представлен полный справочник опкодов, организованных по категориям.

## Полный список Opcode

### Управляющие инструкции (Control Instructions)

Управляют потоком выполнения программы. Структурированные инструкции (block, loop, if) используют явные опкоды `else` и `end` для ограничения вложенных последовательностей инструкций .

| Название | Opcode | Описание |
|----------|--------|----------|
| `unreachable` | 0x00 | Вызывает ловушку (trap)  |
| `nop` | 0x01 | Нет операции  |
| `block` | 0x02 | Блок инструкций  |
| `loop` | 0x03 | Цикл  |
| `if` | 0x04 | Условное выполнение  |
| `else` | 0x05 | Альтернативная ветка `if`  |
| `end` | 0x0B | Конец структурированной инструкции  |
| `br` | 0x0C | Безусловный переход  |
| `br_if` | 0x0D | Условный переход  |
| `br_table` | 0x0E | Табличный переход  |
| `return` | 0x0F | Возврат из функции  |
| `call` | 0x10 | Вызов функции  |
| `call_indirect` | 0x11 | Косвенный вызов функции  |

### Параметрические инструкции (Parametric Instructions)

Работают с операндами любого типа .

| Название | Opcode | Описание |
|----------|--------|----------|
| `drop` | 0x1A | Удаляет значение со стека  |
| `select` | 0x1B | Выбирает один из двух операндов по условию  |
| `select` (с типом) | 0x1C | Выбирает с указанием типа результата  |

Доступ к локальным или глобальным переменным .

| Название | Opcode | Описание |

| `global.set` | 0x24 | Установить значение глобальной переменной  |

### SIMD-инструкции (Vector Instructions)

SIMD-инструкции используют префикс `0xFD` . Полный набор включает около 200 инструкций . Основные категории:

- **Константы:** создание векторов `v128`
- **Загрузка и сохранение:** `v128.load`, `v128.store`, загрузка/сохранение отдельных полос
- **Унарные и бинарные операции:** для `i8x16`, `i16x8`, `i32x4`, `i64x2`, `f32x4`, `f64x2`
- **Сравнения:** побитовые сравнения векторов
- **Преобразования:** `i32x4.trunc_sat_f32x4_s/u`, `f32x4.convert_i32x4_s/u`
- **Расширенное умножение:** `i16x8.extmul_low_i8x16_s/u`
- **Псевдоминимумы/максимумы:** `f32x4.pmin`, `f32x4.pmax`
- **Точечное произведение:** `i32x4.dot_i16x8_s`
- **Popcount:** `i8x16.popcnt`

### Инструкции атомарных операций (Atomic Instructions)

Атомарные инструкции используют префикс `0xFE` . Предназначены для многопоточных приложений с разделяемой памятью.

### Инструкции агрегатных типов (Aggregate Instructions)

Введены с поддержкой сборщика мусора в WebAssembly 3.0 . Работают с `struct` и `array` типами:

- `struct.new`, `struct.get`, `struct.set`
- `array.new`, `array.get`, `array.set`, `array.len`

## Описание инструкций

Инструкции WebAssembly делятся на несколько категорий по функциональности :

1. **Управляющие инструкции** — изменяют поток выполнения, поддерживают структурированное управление (без произвольных переходов).
2. **Параметрические инструкции** — манипулируют стеком без привязки к типам.
3. **Инструкции переменных** — работа с локальными и глобальными переменными.
4. **Инструкции памяти** — доступ к линейной памяти с проверкой границ.
5. **Числовые инструкции** — арифметические и логические операции.
6. **Векторные инструкции (SIMD)** — параллельная обработка данных.
7. **Инструкции ссылочных типов** — работа с непрозрачными ссылками.
8. **Инструкции агрегатных типов** — работа с GC-типами.

## Примеры использования

### Сложение двух 32-битных целых чисел

```wasm
;; Стек: [a, b]
i32.add        ;; Снимает a и b, помещает a+b
;; Стек: [a+b]
```

### Условное выполнение

```wasm
;; Выбор большего из двух значений
(local.get $a)
(local.get $b)
(local.get $a)   ;; Стек: [a, b, a]
(local.get $b)   ;; Стек: [a, b, a, b]
(local.get $a)   ;; Стек: [a, b, a, b, a]
(local.get $b)   ;; Стек: [a, b, a, b, a, b]
i32.gt_s        ;; Стек: [a, b, (a > b)]
select           ;; Выбирает a если условие true, иначе b
```

### Цикл с накоплением суммы

```wasm
;; Вычисление суммы чисел от 0 до n-1
(func $sum (param $n i32) (result i32)
  (local $i i32)
  (local $acc i32)
  (local.set $i (i32.const 0))
  (local.set $acc (i32.const 0))
  
  (block $done
    (loop $loop
      (local.get $i)
      (local.get $n)
      (i32.ge_s)           ;; i >= n
      (br_if $done)

  )
```
